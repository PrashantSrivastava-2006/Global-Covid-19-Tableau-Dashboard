# Tableau workbook

Save/export your finished dashboard as a **Tableau Packaged Workbook (`.twbx`)** and place it in this folder. Suggested filename: `Global_COVID19_Dashboard.twbx`.

Before exporting, verify that the cumulative country rankings, regional comparisons, and maps use one reporting-date snapshot (for the supplied file, the final date is 4 January 2026). Do not sum cumulative snapshots across every date.

If the packaged workbook is too large for GitHub's browser upload interface, use Git/GitHub Desktop or publish the workbook to Tableau Public and link to it from the root README.
